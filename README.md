# SpeedAutoCraft - plugin binaries

Auto-update channel for the SpeedAutoCraft ExileApi plugins.
This repository contains **compiled plugins only** - no source code.

* `version.json` - manifest (version, commit, sha256 of every file)
* `Compiled/<Plugin>/` - drop-in folders for `ExileApi\Plugins\Compiled\`

The OrchestratorPlugin checks `version.json` on startup, downloads changed
files and asks to restart the overlay. Do not edit anything here by hand -
it is regenerated by `publish-update.bat`.

Current version: 2026.10.08-2047
